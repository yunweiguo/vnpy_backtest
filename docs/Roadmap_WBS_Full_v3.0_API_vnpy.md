
# 路线图与任务拆分（Roadmap & WBS）—— 完整版 v3.0（API-first + vn.py）
> 日期：2025-10-25

---

## 1. 里程碑
- **M1（4–6 周）**：OpenAPI/Validator、最小回测 Worker、基础报表与产物、Postman 可跑通；  
- **M2（4–6 周）**：择券/展期/保护翼完整链路、组合净价与拒单补偿、事件日历、决策时间线；  
- **M3（3–4 周）**：一致性治理、异常恢复（幂等/回放）、观测面板、性能基线；  
- **M4（2–3 周）**：参数预设面板、报表导出、策略模板库、CI/调度接入与权限治理。

---

## 2. WBS（按工作流）
### 2.1 Gateway & API
- OpenAPI & JSON Schema；错误码；Idempotency-Key；鉴权（Bearer+API Key）；审计日志；速率/配额。

### 2.2 Validator & Normalizer
- 预设 profiles 展开；点号覆盖；吸附/放宽建议器；越界警告。

### 2.3 Worker（vn.py）
- StrategyCore：Monitor/Selector/ExitRoll/Wing/Executor；  
- 状态机/幂等/OrderJournal；  
- 组合净价/拆腿与补偿；提前指派/到期处理。

### 2.4 数据与事件
- 期权链（US/HK）、Greeks/IV、事件日历（财报/除息/宏观）；  
- 指派概率模型（美式/除息）。

### 2.5 报表与观测
- KPI 指标口径；交易链时间线；决策/订单日志；导出（CSV/JSON/Parquet）；图表。

### 2.6 前端与体验
- 表单→JSON→校验提示；参数预设与推荐范围；运行/对比面板；结果可视化。

---

## 3. 依赖与风险
- 依赖：数据供应商、交易日历、对象存储、队列与调度；  
- 风险：长尾合约流动性不足、IV/Greeks 质量、回测与实盘价差；  
- 缓解：硬门槛与拒单；阈值容差与放宽阶梯；一致性基线与异常场景回归。

---

## 4. 人力与进度（示例）
- 团队：2 后端（含量化）、1 前端、1 QA；双周 Sprint；  
- 指标：M1 结束 Postman 能跑通并产出完整 artifacts；M2 完成多次展期样例回测。

---

## 5. 验收（每里程碑）
- 功能：端到端可跑通；策略模板可用；产物齐全；  
- 质量：单元覆盖≥60%（M1），集成与回归通过；  
- 一致性：设定窗口下回测=模拟偏差 ≤ X%。
