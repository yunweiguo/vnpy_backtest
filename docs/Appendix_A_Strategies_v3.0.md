## A.1 Cash-Secured Put（CSP，现金担保卖出 Put）
### 固定合约
- **进场条件**
  - 指定四要素（symbol/expiry/strike/right=put）+ side=short；现金 ≥ 100×strike×合约数。
  - 流动性：OI≥500、当日量≥100、点差≤权利金的 5–10%。
  - 事件闸：默认 avoid_earnings=true。
- **退场/展期**
  - 止盈：已赚 25–50% 最大利润；止损：亏损≈初始信用 1.5–2.0×；或短腿 Δ≥0.40–0.45/标的触价。
  - 管理窗：DTE ≤ 21；优先 **down & out** 展期到 30–60 DTE，短腿 Δ 重定靶 0.16–0.25。
  - 指派：深 ITM/除息前做 ex-div/assignment 检查；若被指派转为持股，可衔接备兑 Call。
- **可选保护翼**：买小Δ长 Put（0.05–0.10），同到期优先；成本 ≤ 已收信用 20–40%，加翼后保持 credit/width ≥ 1/3（若转成价差）。

### 标的 + 择券/展期（symbol_selector）
- **进场**：target_dte=30–60；短腿 Δ=0.18–0.25；IVR≥50；同上流动性门槛。年化期望收益（AER）≥15%。
- **退场/展期**：同固定合约；优先 down & out；遇财报等事件可先加翼再评估滚动。

## A.2 Covered Call（备兑 Call）
### 固定合约
- **进场**：持股（每合约≥100 股）；指定 short call；避开 earnings；考虑除息提前指派风险。
- **退场/展期**
  - 止盈：已赚 70–90% 权利金；管理窗：DTE ≤ 10。
  - 保留持股：**up/out**（抬价并外推 20–45 天）；接受交割：可不展期。
  - 跌势：按组合风控退出或 **down & out** 提升权利金摊薄成本。
- **可选保护翼**：小额短期 Put，成本 ≤ 已收权利金的 20–40%。

### 标的 + 择券/展期
- **进场**：buy-write 或 overwrite；target_dte=20–45；短腿 Δ=0.20–0.35；IVR≥40–50。
- **退场/展期**：接近行权/已赚 70–90% → up/out；大跌→ down & out；除息/财报注意提前指派。

## A.3 Calendar Spread（日历，同权利同中心，远买近卖）
### 固定合约
- **进场**：远月 long + 近月 short，中心（ATM）一致；优先远月 IV ≥ 近月 IV。
- **退场/展期**
  - 循环：**续卖近月**，保持中心；中心偏离（|S−K|>k×ATR）→ 重置中心或平仓。
  - 管理窗：近腿 DTE ≤ 10；事件期可不卖近月或延期一周。
  - 硬退出：远腿 DTE ≤ 21 或达结构 TP/SL 则整体了结。
- **风险**：中心偏移、IV 崩塌（远 IV 下降）、点差扩大。

### 标的 + 择券/展期
- **进场**：远腿 DTE 60–90；近腿 DTE 7–21；中心 ATM±1 档；term structure 近<远 或 IV_far ≥ IV_near+ε。
- **退场/展期**：循环卖近腿；中心偏移超阈值重置；硬退出同上。

## A.4 Diagonal Spread（对角，不同到期 + 不同执行价）
### 固定合约
- **进场**：远腿 Long（ITM/ATM），近腿 Short（OTM，同方向）；控制净德尔塔（如 +0.2～+0.4 看涨对角）。
- **退场/展期**
  - 近腿周滚/月滚；快速有利时**抬高短腿执行价**锁定时间价值。
  - 远腿 DTE ≤ 21 或达结构 TP/SL 整体了结；点差扩大时先收近腿，择时再卖。
- **可选保护翼**：极端波动前为远腿加反向小翼，对冲 Gamma。

### 标的 + 择券/展期
- **进场**：远腿 DTE 60–90（call-diagonal 远腿 ITM/ATM，近腿 OTM-call；put 类似）。期限结构偏远>近。
- **退场/展期**：近腿滚动与行权价上/下调网格；远腿临期或结构 TP/SL 则整体了结。

## A.5 Straddle（跨式，同到期同执行价 Call+Put）
### 固定合约
- **Long Straddle（借记）**
  - 进场：ATM C+P；DTE ≤ 45（事件/波动型）；
  - 退出：TP +50% / +100%；SL −40% ~ −60%；事件后尽量不过夜；通常不展期。
- **Short Straddle（信用，高风险）**
  - 进场：IVR≥70，避开重大事件；流动性优。
  - 管理：DTE ≤ 21；短腿 Δ 超阈/价格触碰中心±阈值 →
    1) **加翼**→变 Iron Fly（成本 ≤ 已收信用 20–40%）；
    2) 仅滚受威胁侧（out & re-center）；
    3) 结构最大亏损或成交不足 → 退出。
  - 止盈：回购到获利 25–50%。
- **风险**：尾部极大；依赖翼与严格闸门。

### 标的 + 择券/展期
- **Long**：target_dte 14–45；中心 ATM；允许事件玩法需严 SL；通常不滚。
- **Short**：target_dte 30–45；中心 ATM；IVR≥70；管理/展期同固定合约。

## A.6 Butterfly（蝶式，借记，X1<X2<X3，常对称）
### 固定合约
- **进场**：对称结构（X2≈现价）；width = X2−X1 = X3−X2；DTE ≤ 45；低成本博价格收敛至 X2。
- **退场/展期**：TP +50% / +100%；SL −40% ~ −60%；管理窗 DTE ≤ 10；严重偏离或越翼早止损；一般不滚（观点延续→换仓新蝶）。
- **流动性**：OI/量≥300；组合净价下单优先。

### 标的 + 择券/展期
- **进场**：target_dte 14–45；中心 X2≈现价；width 2–8（与价格级别匹配）；避开重大事件（除非专用事件策略）。
- **退场/展期**：同固定合约；通常不滚。

## 参数要点速查（与 Schema 对齐）
- **择券器（Selector）**
  - target_dte：CSP/短权利金 30–60、备兑 20–45、长跨/蝶 14–45、日历/对角 远 60–90 + 近 7–21。
  - short_delta：CSP/信用腿 0.18–0.25；短跨中心=ATM。
  - width：信用/蝶/铁鹰 2–8 档；iv_rank_min：信用/短跨/铁鹰 ≥ 50（短跨≥70）。
  - min_credit_of_width（信用结构）：≥ 1/3。
- **展期（RollPolicy）**
  - manage_at_dte_lte=21；roll_to_dte=30–60；threatened_side_only=true；delta_retarget：put 0.16–0.25 / call 0.20–0.30。
- **退出（ExitPolicy）**
  - 信用：TP 25–50%；SL 1.5–2.0×credit；
  - 借记：TP +50% / +100%；SL −40% ~ −60%；
  - 硬退出：hard_exit_dte_lte 视结构：短权利金 7–10；日历按远腿 ≤21。
- **保护翼（WingPolicy）**
  - wing_delta 0.05–0.10；max_cost_pct_of_credit 20–40%；加翼后保持 credit/width ≥ 1/3。
- **流动性（LiquidityGate）**
  - OI≥500（部分结构≥300）、量≥100、点差≤5–10%（借记可适度放宽）。
- **事件闸（EventGate）**
  - 默认 avoid_earnings=true；除非启用 allow_event_play 的专门策略。
